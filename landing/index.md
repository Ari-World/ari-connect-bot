## How It Works

<div class="steps-grid">

<div class="step">
<span class="step-number">1</span>

### Opt-In Connection
Server admins choose which channels to connect and to which lobby. No data is shared without explicit consent.
</div>

<div class="step">
<span class="step-number">2</span>

### Real-Time Relay
Messages sent in a connected channel are instantly relayed to all channels in the same lobby via Discord webhooks — preserving usernames and avatars.
</div>

<div class="step">
<span class="step-number">3</span>

### Moderation Across All
Mutes, filters, and bans applied by any moderator propagate across the entire lobby. One bad actor can't jump servers to bypass moderation.
</div>

<div class="step">
<span class="step-number">4</span>

### Web Portal Sync
Events, polls, and analytics sync to the web portal in real time. Admins can post back to Discord from the dashboard, closing the loop.
</div>

</div>
